# Vagner Caldeira

A Next.js portfolio for a senior backend and full-stack engineer. The app is a static export.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` to generate a deployable static site in `out/`.

Career entries, contact links, and the featured projects live in `app/content.js`. To publish a case study link, add an `href` to its project entry. The card will show a case study link automatically. The downloadable résumé lives in `public/`.
